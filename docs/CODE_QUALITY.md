# Code quality — AirWise
The app reuses shared HTTP/auth helpers, schema validation, injected provider transport, safe text rendering, strict domain/server checking, ESLint, formatting and CI. Legal document schemas, prompts, parsing dependencies and examples have been removed. Decision rules, AQI categories and transport arithmetic are deterministic and tested independently of model output. Data freshness failures are explicit. Gemini cannot add unapproved advice IDs. See current README and verification report for limits.
